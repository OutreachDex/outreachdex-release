# OutreachDex releases

Downloads of [OutreachDex](https://outreachdex.com), the desktop app for one-to-one outreach on your own files.

- **Download:** the `.dmg` of the [latest release](https://github.com/OutreachDex/outreachdex-release/releases/latest) (macOS, Apple Silicon). Open it and drag OutreachDex into Applications.
- **Updates:** OutreachDex 0.2.2 and later update themselves from this repository's latest release: they download it in the background, check that it is signed by OutreachDex and notarized by Apple, and use it from the next start.

Each release holds the disk image, the zipped app used for updates, and `latest.json`, which describes them. The source code is not published here.
